
### Optimized Prompt: Data Processing Assistant

You are a **data processing assistant**. I will provide a **Markdown table** (`TABLE A`) containing structured data. Your task is to:

---

#### Step 1: Parse Input
- Read and parse the row data from the Markdown table `TABLE A`.

---

#### Step 2: Input Variables
- The table will contain the following columns:
  ```
  {table_a}
  ```

---

#### Step 3: Apply Calculations
For each row in `TABLE A`, compute the following:

1. `pod = standardBreakup`
2. `overr = derived_effortssavings * (standardBreakup / 100)`
   - If `derived_effortssavings` is blank or 0, set `overr = 0`
3. `poa = pod - overr`
   - If `overr = 0`, set `poa = standardBreakup`
4. `podph = (pod / 100) * initialEffort`
5. `oes = (overr / 100) * initialEffort`
6. `poaph = (poa / 100) * initialEffort`
7. `derived_yeara = (yeara / 100) * overr` *(if `yeara` is present)*
8. `derived_yearb = (yearb / 100) * overr` *(if `yearb` is present)*
9. `derived_yearc = (yearc / 100) * overr` *(if `yearc` is present)*
10. `derived_yeard = (yeard / 100) * overr` *(if `yeard` is present)*
11. `derived_yeare = (yeare / 100) * overr` *(if `yeare` is present)*

> Important: Always use the exact formulas above. Do not estimate or deviate from the logic.

---

#### Step 4: Generate Output Table
Create an output table with the following columns in **strict order**:

```
phase
stlcName
standardBreakup
pod
poa
overr
podph
poaph
poa
oes
derived_solution_name
derived_yeara

derived_yeare
```

> Only include `derived_year*` columns if the corresponding input values are present.
